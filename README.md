# 代码统计工具

一个带图形界面的本地代码统计工具。选择一个目录，自动统计代码字数、行数、注释行、最早的创建时间等。
日志与二进制文件自动排除；配置文件同样计入统计，但单独列出来，不与代码混淆。

## 运行

```bash
python code_stat_gui.py
```

Windows 下也可以直接双击 `code_stat_gui.py`。需要 Python 3.8 以上（开发环境为 3.14）。

**零硬依赖**，只用标准库。若环境中已装 `charset-normalizer`（`requests` 的传递依赖，通常已有），
自动用它提升非 UTF-8 文件的编码识别率；没装也能正常运行。

打包成单个 exe 发给别人：

```bash
pip install pyinstaller
pyinstaller -F -w -n 代码统计工具 code_stat_gui.py
```

## 统计口径

### 字数与行数
每个文件统计以下指标：

| 指标 | 说明 |
|---|---|
| 总字符 | 文件解码后的全部字符数，含空格与换行 |
| 不含空白 | 排除所有空白字符后的字符数 |
| 总行数 | `splitlines()` 的结果，即文件的行数 |
| 代码行 | 非空、且不是整行注释的行 |
| 注释行 | 整行注释的行 |
| 空行 | `strip()` 后为空的行 |

约定：**同一行既有代码又有注释的，计入代码行**（如 `x = 1  # 说明`）。因此
`代码行 + 注释行 + 空行 = 总行数` 恒成立。

### 分类
扫码到的文件分三类，汇总面板分三张卡片分别显示：

- **代码**：`.py` `.c` `.js` `.ts` `.go` `.rs` 等近 100 种源码扩展名，按语言归类
- **配置**：`.json` `.yaml` `.toml` `.ini` `.env` `.xml` 等，外加 `Makefile` `Dockerfile`
  `CMakeLists.txt` `.gitignore` `requirements.txt` 这类无扩展名的构建/配置文件
- **文档**：`.md` `.txt` `.rst` 等，可在界面上取消勾选「统计文档」将其排除

### 不统计的内容
两重过滤：

1. **扩展名黑名单**：日志（`.log` `.out` `.err`）、二进制与可执行（`.exe` `.dll` `.so` `.o`
   `.class` `.pyc`）、图像媒体（`.png` `.jpg` `.mp3` `.mp4`）、归档（`.zip` `.tar` `.gz`）、
   数据库（`.db` `.sqlite`）、字体、锁文件等
2. **内容探测**：读取文件头部，若含 NUL 字节或不可打印字符占比超过 30%，判为二进制并跳过
   ——这一层用于兜住**没有扩展名**的二进制文件

被跳过的内容不会凭空消失，全部记在「跳过明细」页里，可以核对自己预期要统计的文件有没有被误伤。

### 时间
Windows 上 `st_ctime` 就是文件创建时间，`st_mtime` 是最后修改时间，两者都统计并显示：

- 最早创建时间（含对应文件名）
- 最早修改时间 / 最近修改时间

## 界面说明

顶部选择目录、设置选项，点击「开始统计」。扫描在后台线程执行，不会卡住界面，可随时点「取消」。
大目录下进度条按预扫的文件总数推进。

结果分五个标签页：

| 标签页 | 内容 |
|---|---|
| 目录树 | 可逐级展开到文件，父节点显示整棵子树的汇总；有「全部展开 / 全部折叠」 |
| 文件列表 | 每个文件一行，13 列；表头点击排序，顶部可按路径关键字筛选 |
| 按语言 | 各语言的字符数、行数、注释行等，用于看语言占比 |
| 跳过明细 | 什么原因跳过了多少东西、示例路径，以及读取失败的文件清单 |
| 按目录 | 按一级子目录汇总，看哪个模块代码量最大 |

## 导出

- **导出本页 CSV**：导出当前标签页（含目录树，按缩进体现层级）
- **导出全部 CSV**：一次导出 `summary.csv`、`files.csv`、`languages.csv`、
  `directories.csv`、`skipped.csv` 五个文件
- **导出完整 JSON**：含全部分类汇总、语言分布、跳过明细、每个文件的完整指标与时间
- **导出 HTML 报告**：自包含的单文件报告，带汇总卡片、语言分布条形图，可直接分享

CSV 一律写 `utf-8-sig`（带 BOM），Excel 打开不会中文乱码。

## 文件结构

```
code_stat_gui.py    入口与界面（tkinter）
stats_core.py       扫描与统计引擎，不依赖 tkinter，可单独 import 做 CLI 或测试
file_classify.py    分类规则表：忽略目录、忽略扩展名、语言映射、注释风格、二进制探测
```

想加一门语言或一类配置文件，只改 `file_classify.py` 顶部的表即可，无需动其他文件。

## 自定义

### 增加代码/配置扩展名
编辑 `file_classify.py`：

```python
CODE_EXT = {
    ".xyz": "MyLang",      # 新增语言
    ...
}
```

### 增加忽略目录
```python
IGNORE_DIRS = frozenset({
    "我的构建产物",         # 新增
    ...
})
```
「忽略常见目录」的勾选框关闭后，这些目录会被照常扫描。

### 注释风格
`COMMENT_STYLES` 字典把语言映射到 `(行注释前缀元组, 块注释对)`：

```python
"MyLang": (("#", "--"), ("/*", "*/")),   # 支持 # 和 -- 行注释与 /* */ 块注释
```

未登记的语言按「无注释」处理，此时所有非空行都算代码行。

## 已知取舍

- 注释统计是逐行状态机的**近似**实现：不解析字符串字面量，所以 `url = "http://x"` 这类
  含 `//` 的行不会被误判为注释，但 `s = "a /* b"` 这种跨引号的伪块注释会算错。这是为性能
  做的取舍，对绝大多数代码库无影响。
- 单行块注释（如 `/* x */`）在整行只有注释时计为注释行；块注释跨行时，每一行都算注释行。
- 结果超过 2000 个文件时，文件列表只渲染前 2000 行以保证界面响应速度，
  完整数据请用导出功能。
- 按「跳过明细」里的示例路径核对时，示例最多记录 50 个。
